# Практика: Инструменты тестировщика (QA Tools)

В этом репозитории собраны практические работы по использованию основных инструментов тестировщика. 

## 🛠 Стек технологий и инструментов
* **Postman:** Проектирование запросов, автотесты (JavaScript), использование переменных окружения.
* **Charles Proxy:** Перехват и подмена трафика (Rewrite, Breakpoints), симуляция слабого соединения (Throttle).
* **DevTools:** Анализ сетевого трафика (Network), работа с LocalStorage/Cookies, поиск ошибок фронтенда (Console).
* **SQL:** Написание запросов (JOIN, GROUP BY, агрегатные функции).
* **Брокеры сообщений (Kafka):** Понимание принципов асинхронного взаимодействия, топиков, партиций и консьюмеров.
* **Документация:** Swagger, чтение спецификаций API.

## 📂 Структура проекта
* `01_DevTools_Report.md` — отчет по анализу сетевого трафика и кэша.
* `Petstore_QA_Practice.postman_collection.json` — готовая коллекция для Postman с CRUD-операциями и автопроверками.
* `03_API_Test_Cases.md` — тест-кейсы для проверки API по спецификации Swagger.
* `04_Charles_Proxy_Bugs.md` — баг-репорты, найденные с помощью перехвата трафика (включая баг двойного списания).
* `05_SQL_Queries.sql` — скрипт с примерами выборок из БД.
* `06_Kafka_Scenarios.md` — тестовые сценарии проверки интеграции через Kafka.
