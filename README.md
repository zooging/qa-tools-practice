## 🛠 Стек технологий и инструментов
* **Postman:** Проектирование запросов, автотесты (JavaScript), использование переменных окружения.
* **Charles Proxy:** Перехват и подмена трафика (Rewrite, Breakpoints), симуляция слабого соединения (Throttle).
* **DevTools:** Анализ сетевого трафика (Network), работа с LocalStorage/Cookies, поиск ошибок фронтенда (Console).
* **SQL:** Написание запросов (JOIN, GROUP BY, агрегатные функции).
* **Брокеры сообщений (Kafka):** Понимание принципов асинхронного взаимодействия, топиков, партиций и консьюмеров.
* **Документация:** Swagger, чтение спецификаций API.
