## 📝 2. Тест-кейсы (Test Cases)

### TC-01: Успешная регистрация нового пользователя
* **Предусловия:** Пользователь не зарегистрирован в системе. Открыта страница регистрации.
* **Шаги:**
  1. Ввести уникальный валидный email (`newuser@test.com`) в поле «Почта».
  2. Ввести валидный пароль (`Qwerty123!`) в поле «Пароль».
  3. Ввести тот же пароль в поле «Повтор пароля».
  4. Активировать чекбокс согласия с правилами.
  5. Нажать кнопку «Зарегистрироваться».
* **Ожидаемый результат:** Пользователь успешно зарегистрирован. Происходит редирект на главную страницу, отображается toast-сообщение об успехе.

### TC-02: Попытка регистрации с несовпадающими паролями
* **Шаги:**
  1. Ввести валидный email в поле «Почта».
  2. Ввести пароль `Password123` в поле «Пароль».
  3. Ввести пароль `Password321` в поле «Повтор пароля».
  4. Активировать чекбокс согласия с правилами.
  5. Нажать кнопку «Зарегистрироваться».
* **Ожидаемый результат:** Регистрация отклонена. Под полем «Повтор пароля» отображается сообщение «Пароли не совпадают».

### TC-03: Попытка регистрации без согласия с правилами
* **Шаги:**
  1. Заполнить валидными данными поля: «Почта», «Пароль», «Повтор пароля».
  2. Убедиться, что чекбокс согласия с правилами **не активирован**.
  3. Попытаться нажать кнопку «Зарегистрироваться».
* **Ожидаемый результат:** Кнопка «Зарегистрироваться» находится в состоянии `disabled` (неактивна).

### TC-04: Попытка регистрации с некорректным форматом email
* **Шаги:**
  1. Ввести email без символа `@` (например, `userexample.com`) в поле «Почта».
  2. Заполнить остальные обязательные поля.
  3. Нажать кнопку «Зарегистрироваться».
* **Ожидаемый результат:** Под полем «Почта» появляется валидационная ошибка «Некорректный формат email». Запрос на сервер не отправляется.

### TC-05: Попытка регистрации с уже существующим email
* **Предусловия:** В БД существует пользователь с email `exist@test.com`.
* **Шаги:**
  1. Ввести `exist@test.com` в поле «Почта».
  2. Заполнить остальные обязательные поля валидными данными.
  3. Нажать кнопку «Зарегистрироваться».
* **Ожидаемый результат:** Регистрация отклонена. Появляется сообщение об ошибке «Пользователь с таким email уже существует».
