## 🐛 2. Баг-репорты

### [BUG-001] Отсутствует маскировка вводимых символов в поле «Пароль»
* **Environment:** Web (Google Chrome 118, Windows 11)
* **Severity:** Critical (Угроза компрометации данных)
* **Priority:** High

**Шаги для воспроизведения:**
1. Открыть форму входа.
2. Установить фокус в поле «Пароль».
3. Ввести тестовые данные (например, `qwerty123`).

**Ожидаемый результат:** Введенные символы скрыты (замаскированы точками/звездочками) согласно требованиям безопасности (`type="password"`).
**Фактический результат:** Символы отображаются открытым текстом.

### [BUG-002] Раскрытие информации о существовании пользователя при ошибке авторизации
* **Environment:** Web (Google Chrome 118, Windows 11)
* **Severity:** Medium
* **Priority:** Medium

**Шаги для воспроизведения:**
1. Открыть форму входа.
2. Ввести email существующего пользователя в поле «Почта».
3. Ввести заведомо неверные данные в поле «Пароль».
4. Нажать кнопку «Войти».

**Ожидаемый результат:** Появляется унифицированное сообщение «Неверная почта или пароль».
**Фактический результат:** Появляется сообщение «Неверный пароль», что позволяет злоумышленникам проверять (брутфорсить) базу email-адресов.
